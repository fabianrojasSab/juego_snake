# 🐍 Snake Game - Vanilla JS Edition

Un juego clásico de la culebra (Snake), desarrollado en JavaScript moderno (ES6), usando módulos y canvas HTML5.

---

## 🎮 Demo

Puedes jugar directamente abriendo el archivo `index.html` en tu navegador (recomendado usar un servidor local para soporte de módulos ES6).

---

## 🧠 Características

- ✅ Código modular y limpio con clases separadas
- ✅ Movimiento fluido de la serpiente
- ✅ Colisión con comida, cuerpo y bordes
- ✅ Sistema de puntaje
- ✅ Guardado del puntaje más alto (localStorage)
- ✅ Canvas responsivo y controles por teclado
